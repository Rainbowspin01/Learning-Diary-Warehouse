# 作用域链
    作用域链是指V8引擎在执行函数时，会创建一个执行上下文，查找变量时，会先在当前执行上下文查找，如果不在当前执行上下文，会顺着outer继续查找上一级执行上下文，直到找到。如果找到，会返回找到的变量；如果没有找到，会返回undefined。如果在全局执行上下文，也没有找到，会报错。

# 闭包
    在js中，根据词法作用域的规则，内部函数总是可以访问其外部函数的变量。当函数A内部有一个函数B，且函数B被外部调用时，即使函数A执行完毕，它的执行上下文也无法被完全销毁。其中被函数B引用的变量会以一个集合的方式被保留在调用栈中，这个集合被称为闭包。

    -缺点：内存泄漏
    -优点：延长变量的生命周期，封装私有变量
