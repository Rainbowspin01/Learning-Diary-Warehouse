#作用域
1.全局作用域
2.函数作用域
3.块级作用域:let，const+{}语句块会创建一个块级作用域

-作用域访问规则：
1.函数内部可以访问函数外部的变量
2.函数外部不能访问函数内部的变量
3.函数内部可以访问函数外部的参数
4.函数内部可以访问函数外部的变量

##词法作用域
-词法作用域是指在函数调用时，函数体中的变量引用的是函数定义时的作用域，而不是调用时的作用域。

#栈
-栈是一种先进后出的数据结构，用于存储函数调用时的变量和返回地址。
-栈的每个元素都是一个函数调用帧，包含函数调用时的变量和返回地址。
-栈的顶部是当前正在执行的函数调用帧。
