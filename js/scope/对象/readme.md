# 构造函数
 - 被new调用的函数
 - 用于批量创建实例对象
 
 1. js 官方提供了Object，Array，Function等构造函数，用于创建对象、数组、函数等实例对象

 ## prototype 原型 （显式原型）
 - prototype是每一个函数天生就拥有的一个属性，且它是一个对象
 
 ## __proto__对象原型（隐式原型）
 - __proto__是对象天生就拥有的一个属性，且它是一个对象

 ### 实例对象的隐式原型等于构造函数的显式原型
 - v8 引擎在访问对象的属性时，会先查找对象本身显式拥有的属性，如果没有，就会去对象的隐式原型上查找

 # 包装类
 - 原始类型不能添加属性和方法

 - 当用户创建一个字幕，字面量时，v8会默认执行new Xxx()，得到一个对象实例
 - 因为原始类型不能添加属性和方法，所以，v8在new出这个实例对象后，会立即做一个拆箱操作
 - 所以给原始类型添加属性和方法，最后访问得到的其实是实例对象是不存在的属性和方法，也就是undefined
