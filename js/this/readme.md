# this 是什么
- 是一个关键字，它提供了一种更优雅的方式传递一个对象的引用，可以让代码更简洁、更易懂。

# this 可以出现在哪里
 1. this出现在全局就指向window
 2. 函数体内

 # this 指向
 1. 默认绑定规则————当函数独立调用时，函数中的this指向window
 2. 隐式绑定规则————当一个函数被一个对象所拥有，并被该对象所调用时，函数中的this指向该对象
 3. 显式绑定规则————当一个函数被调用时，通过call、apply、bind方法来改变this指向
 4. new绑定规则————因为new的原理中存在显示绑定规则，被作为构造函数调用时，函数中的this指向它创建的实例对象
 5. 箭头函数绑定规则————箭头函数没有this这个概念，写在箭头函数中的this，也是它外层那个非箭头函数中的
 
 # 原型的问题
 - 原型链:v8在查找对象中的属性时，会先查找对象显示拥有的属性，如果没有，就会顺着对象的隐式原型往上走，还找不到，就继续顺着原型链往上走，直到找到null为止
