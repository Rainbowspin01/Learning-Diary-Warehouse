# 代码执行耗时吗？
- 程序中存在一些耗时的任务，比如：网络请求、定时器等。这些任务我们称之为异步任务。

# 异步
- js默认是单线程执行的：意味着同一时间只能执行一个任务。

- 耗时的任务回阻塞后续代码的执行，这样会导致程序的执行效率降低。所有js设计了一个事件循环机制来处理异步任务。

# 处理异步任务
- js会先将同步代码执行完毕，然后才会执行异步任务。而在某种情况下，我们希望在异步任务完成后，再执行后续代码。

1. 回调函数:
    将后面要执行的函数作为参数传给前面的异步函数，这就会导致前面的异步函数执行完毕后，再执行后面的函数。
    缺点：当异步函数嵌套过多时，会导致回调地狱（排查问题困难，代码可读性低，难以维护）。

# Promise工作原理
1. Promise中存在三种状态：
    - pending：进行中状态
    - fulfilled：成功状态
    - rejected：失败状态
2. 当Promise对象的状态从pending变成fulfilled时，then方法中的回调函数就会执行。
- then方法可以返回一个Promise对象，他的状态会继承于上一个Promise对象。
- 当人为返回一个Promise对象时，then就不会启用自己的Promise对象，而是采用人为返回的Promise对象。
3. 当Promise对象的状态从pending变成rejected时，catch方法中的回调函数就会执行。
